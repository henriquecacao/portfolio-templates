# ESMP — wayfinding system (case study)

Group project at IADE (2023): a visual identity and wayfinding system for Escola Secundária Marquês de Pombal, built from the school's own tiles. Henrique designed it with Bárbara Pinho and Gabriela Ramos; the three of them developed the visual system, shape studies and mockups together.

- `index.html` — the case study. Generated once from the team's brand book, then edited by hand. Each chapter is a `<section class="chapter">`.
- `css/styles.css` — dressed in the project's own system: Azulejo / Sol / Saudade colours. Archivo (condensed) stands in for Auton, and Figtree for Filson Pro.
- `js/main.js` — draws the component in SVG (hero mark, tile band, nav arrows), runs the sign-style section nav, reveal-on-scroll and the lightbox.
- `assets/` — WebP exports of the brand-book spreads, mockups and site photos.

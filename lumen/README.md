# Project Lumen — 3D game concept (case study)

Solo project for Integrated Project III at IADE (2026): a first-person 3D exploration game built in Blender and Unity, with its concept book, 3D renders, UI, poster and an AI-generated trailer.

- `index.html` — the case study: trailer, story, character, world, gameplay & UI, identity.
- `css/styles.css` — dark page in the game's palette. Barlow Condensed stands in for DIN Engschrift.
- `js/main.js` — the hero "headlight" (follows the pointer, drifts by itself on touch screens), the HUD (Light meter = scroll progress, inventory slots unlock per chapter), trailer taglines, reveal and lightbox.
- `assets/trailer.mp4` — the original trailer, remuxed for fast start (not re-encoded).
